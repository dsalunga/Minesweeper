# Minesweeper Rust

Console Minesweeper implementation in Rust.

## Requirements

- Rust toolchain (includes `cargo`)

## Run

From repository root:

```bash
cd rust
cargo run
```

## Optional commands

```bash
cargo build --release
cargo test
```

## Gameplay notes

- Enter board size as two numbers (for example `9 9`).
- Enter mine count less than the total number of cells.
- Enter moves using coordinates like `A1`.
