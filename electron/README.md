# Minesweeper · Electron

Cross-platform desktop Minesweeper with a neon dark theme.

## Run

```bash
cd electron
npm install
npm start
```

## Controls

- Left-click — reveal
- Right-click — flag (cycles flag → ? → hidden)
- Middle-click or Left+Right together — chord-reveal a numbered cell

Difficulty presets (Beginner / Intermediate / Expert / Custom) and live timer included.
