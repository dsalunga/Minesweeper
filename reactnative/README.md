# Minesweeper · React Native (Expo)

Cross-platform Minesweeper for iOS, Android, and Web using Expo.

## Run

```bash
cd reactnative
npm install
npx expo start
```

Then press `i` for iOS simulator, `a` for Android emulator, or `w` to open in a browser.

## Controls

- **Tap** — reveal (or flag, in flag mode); chord-reveals on revealed numbered cells
- **Long-press** — flag (or chord on numbered cells)
- **Mode toggle** — switch between Reveal / Flag for thumb-friendly play
- **Presets** — Beginner / Intermediate / Expert
